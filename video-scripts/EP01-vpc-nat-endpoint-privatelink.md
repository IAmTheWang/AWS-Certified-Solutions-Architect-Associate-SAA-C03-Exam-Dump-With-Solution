# EP01｜封闭小区的三条出路：NAT、Gateway Endpoint、PrivateLink

*系列：AWS 人话课 · 时长 3:00 · 来源：`notes/VPC-Endpoint-Gateway-vs-Interface-vs-NAT-Gateway.md`*

**一句话核心**：私有子网想访问外面，有三条路——NAT 走公网最贵，Gateway Endpoint 只通 S3/DynamoDB 且免费，PrivateLink 通大多数服务按量收费。

**贯穿比喻**：VPC 私有子网 = 高安全封闭小区；三个组件 = 三种出入通道。

---

## 0:00–0:15 钩子

**画面**：一个只有围墙、没有门的小区俯视图，服务器小人在墙里挠头。

**口播**：
> 你的服务器住在一个封闭小区里，大门焊死，外面进不来，里面也出不去。那它怎么下载更新，怎么把文件存进 S3？今天三分钟，讲清 AWS 的三条通道，它们的价格，最多差了四倍多。

## 0:15–0:45 场景

**画面**：小区图，标注"VPC 私有子网"。

**口播**：
> 先把画面想清楚。VPC 的私有子网，就是一个高安全封闭小区。服务器是居民，默认和外界完全隔绝。想出去办事，物业给你开了三种通道。具体到考题，常见的场景是：应用在私有子网里，要调用 S3 的 API 存取对象，公司安全规定，流量不允许经过互联网。这时候该选哪条通道，就是考点。

## 0:45–1:25 通道一：NAT Gateway

**画面**：小区门口一个只能出的闸机，居民把包裹递出去，门卫跑去"公网大马路"取回来；路人想进被拦下。

**口播**：
> 第一种，NAT Gateway，是小区的单向出口门卫。居民要下载更新、调用外部接口，门卫替你跑到公网大马路上，把东西拿回来。但外面的陌生人想反过来闯进小区，门卫死死拦住。所以它只出不进。它能去任何公网地址，通用性最强，代价是最贵：每个月固定三十多美元，每处理一个 G 的流量，再收四分半美分。它不是为了省钱才用的，真正的原因是安全：服务器不用暴露公网 IP，外面没法直接扫描，所有出网流量也集中在一个出口，方便审计。

## 1:25–2:00 通道二：Gateway Endpoint

**画面**：小区后墙凿开一扇门，门后只有两栋楼：S3、DynamoDB。门上贴"免费"。

**口播**：
> 第二种，Gateway Endpoint，是小区后墙上凿出来的一扇免费专用门，直通隔壁的自来水厂。注意，这个水厂只有两家：S3 和 DynamoDB。走这扇门，流量完全不出 AWS 内网，不上公网大马路。原理也很朴素，就是在路由表里加一行：目标是 S3 的地址段，就走这扇门。最关键的一点：它免费。而且哪怕你的服务器在私有子网里，一个公网出口都没有，也照样能调用 S3。

## 2:00–2:35 通道三：PrivateLink

**画面**：客厅墙上装了一个接线盒，标注"ENI · 小区内部 IP"，线连到各种服务图标。

**口播**：
> 第三种，PrivateLink，也叫 Interface Endpoint，像是把服务商的接线盒，直接装进你家客厅。AWS 会在你的子网里生成一块虚拟网卡，拿一个小区内部的私有 IP。你访问对方服务，域名解析出来就是这个内网地址，连小区大门都不用出。SQS、SNS、KMS，还有在 AWS 上提供服务的第三方，都能用它。价格适中，单个可用区每月七块多，每个 G 一美分。代价是，它真的要占用网卡和 IP，通常每个可用区建一个，这也是它收费的原因。

## 2:35–2:50 实战省钱

**画面**：账单柱状图，NAT 那根柱子很高；加了 Gateway Endpoint 后矮下去。

**口播**：
> 实战里最常见的省钱操作：你的服务器既要上网，又要往 S3 传海量日志。别让 S3 流量走 NAT，那是按 G 烧钱。配一个免费的 Gateway Endpoint，S3 走后门，剩下的流量才走门卫。

## 2:50–3:00 考试口诀 + 结尾

**画面**：三行口诀大字，最后一行"NAT = 走公网"画红叉。

**口播**：
> 考试记两句。私有子网访问 S3 或 DynamoDB，不能走公网，选 Gateway Endpoint；访问其他 AWS 服务，选 PrivateLink。千万别选 NAT，它恰恰走公网，方向搞反了。下期讲 ALB 和 API Gateway。

## 讲之前核对（别讲错）

- 价格数字来自笔记里的 **us-east-1 定价示例**：NAT 约 $32.4/月 + $0.045/GB；PrivateLink 单 AZ 约 $7.2/月 + $0.01/GB。发布前请对照官网当前价，视频里最好加字幕"以官网为准"。
- "只有 S3 和 DynamoDB 用 Gateway Endpoint"是考试口径；"第三方 SaaS 能用 PrivateLink"的前提是对方把服务挂在 AWS 的 NLB 后面，对方不在 AWS 上就用不了。
- 干扰项（可作为评论区互动）：①"把 S3 桶建在私有子网"不成立，S3 没有 ENI；②"同 Region"只影响延迟和跨区费用，与是否走公网无关。
